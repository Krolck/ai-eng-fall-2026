# Python Calculator App

A simple calculator application built with Python and Tkinter.

## Run it

From this folder, run:

```bash
python calculator.py
```

## Features

- Basic arithmetic: +, -, *, /
- Percentage support
- Decimal numbers
- Parentheses support
- Clear and backspace
- Keyboard input support

## Notes

This app uses Tkinter, which is included with most Python installations on Windows, macOS, and Linux.
